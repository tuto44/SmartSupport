#Acceso a Citrix

Para comenzar, acceda a la dirección URL https://mymfa.whirlpool.com/ e inicie sesión
utilizando sus credenciales habituales de W-Pass (usuario y contraseña).

Una vez dentro del panel principal, localice y seleccione la opción denominada Citrix.

Tenga en cuenta que, si la opción de Citrix no se encuentra visible, deberá gestionar los
permisos de acceso a través de W-Pass. Puede realizar este trámite haciendo clic aquí.

A continuación, el sistema presentará la pantalla de autenticación de identidad. Elija la
modalidad “Recibir un código por SMS” y proceda a ingresar el código de verificación
enviado a su dispositivo móvil.

Tras completar la autenticación, utilice la herramienta de búsqueda para encontrar la aplicación
“SAP GUI”. Se recomienda marcarla como favorita para agilizar futuros ingresos. Haga doble
clic sobre la aplicación y presione el botón “Abrir”.

Posteriormente, el sistema descargará de forma automática un archivo de acceso; ejecútelo
haciendo doble clic sobre él.

Aviso Importante: Es necesario descargar y ejecutar este archivo cada vez que requiera
acceder a SAP a través de la plataforma Citrix.

Al iniciar el archivo, se desplegará una ventana de advertencia de seguridad; por favor, haga
clic en la opción “Permitir el uso”.

Cuando se abra el entorno de SAP, navegue hasta la carpeta “LAR” y acceda mediante doble
clic a la conexión identificada como “MP0”.

Finalmente, podrá ingresar al sistema validando su identidad con sus credenciales de W-Pass.
