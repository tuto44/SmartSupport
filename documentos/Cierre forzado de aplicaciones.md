# Forzar Cierre de Aplicaciones que no Responden

Si una aplicación deja de responder tras un tiempo de espera prudencial, se recomienda finalizar el proceso manualmente desde el administrador de tareas y reiniciar la aplicación para restaurar su funcionamiento.

## 1. Apertura del Administrador de Tareas
Puede ingresar mediante dos opciones:
- **Opción 1:** Presione la combinación de teclas **CTRL + Shift + ESC**. Este comando abrirá el administrador de tareas de inmediato.
- **Opción 2:** Ponga el cursor encima del icono de **Windows** en la barra de tareas, dé clic derecho y seleccione **“Administrador de tareas”** en la lista desplegable.

> **Nota visual:** [NOTA PARA LA IA: Se visualiza el menú contextual de Windows con la opción Administrador de tareas resaltada].

## 2. Detener la aplicación
1. Una vez dentro del administrador de tareas, ubique la aplicación que desea detener.
2. Dé clic derecho sobre la aplicación y seleccione **"Finalizar tarea"**.

> **Nota visual:** [NOTA PARA LA IA: Se visualiza el Administrador de tareas con una aplicación seleccionada y el menú desplegado en "Finalizar tarea"].
