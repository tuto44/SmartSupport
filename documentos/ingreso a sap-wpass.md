# Problemas de Ingreso a Aplicaciones Whirlpool (SAP)

## 1. Restablecimiento de credenciales
Si el sistema no le permite ingresar a alguna aplicación corporativa de Whirlpool (frecuentemente **SAP**), el problema suele deberse a la desincronización de la cuenta.
1. Realice un cambio de contraseña en el portal **WPASS**.
2. Aplique el proceso de **resincronización** y **desbloqueo de aplicaciones**. *(Nota: Consulte el manual específico de WPASS para ejecutar estos pasos a detalle).*
