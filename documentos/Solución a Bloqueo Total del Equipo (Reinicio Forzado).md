# Solución a Bloqueo Total del Equipo (Reinicio Forzado)

Si el computador se bloquea por completo y el sistema no responde a ninguna interacción (pantalla o periféricos congelados), es necesario realizar un apagado forzado de hardware.

## 1. Pasos para el reinicio forzado
1. Mantenga presionado el **botón de encendido** del equipo por aproximadamente **10 segundos** hasta que la máquina se apague por completo.
2. Suelte el botón de encendido.
3. Espere un lapso de **5 segundos** para permitir que el sistema se estabilice y los componentes pierdan la energía residual.
4. Presione el **botón de encendido** una sola vez para encender el equipo con normalidad.

> **Aviso Importante:** Este procedimiento debe utilizarse únicamente como último recurso cuando el equipo no responde de ninguna otra manera (ni siquiera a comandos como `CTRL + Shift + ESC`), ya que un apagado abrupto puede ocasionar la pérdida del trabajo no guardado.
